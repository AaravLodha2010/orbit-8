03 / about this machine
Orbit-8 is a hands-on lab for the Crescent-8 CPU.
Crescent-8 has four 8-bit registers, 256 bytes of RAM, a program counter, stack pointer, flags, and a fetch/decode/execute cycle.
Addresses F0–FF are a bit-packed 16×8 display. The stack grows downward in E0–EF. Press A, D, or Space to write input to the input port.
Try changing a number, assembling, then stepping through the program.
